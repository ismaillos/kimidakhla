# Dakhla Artisanal

Produits naturels du Sahara Marocain.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deployed on Vercel with auto-deployment from GitHub.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## Features

- WhatsApp ordering
- Multi-language support
- Blog with SEO
- Product catalog
- Search functionality
- PWA support
- Google Analytics
- Facebook Pixel
- Google Ads conversion tracking
