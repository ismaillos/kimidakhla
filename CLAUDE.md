# Dakhla Artisanal - Claude Context

## Project Overview
- **Name**: Dakhla Artisanal
- **Type**: E-commerce website for natural Moroccan products
- **Tech Stack**: React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **Deployment**: Vercel (static)
- **Domain**: https://www.dakhlaartisanal.com

## Key Features
- WhatsApp ordering integration
- Facebook Pixel tracking
- Google Analytics 4
- Google Ads conversion tracking
- Google Sheets order submission
- Multi-language support (FR, AR, EN, ES)
- Blog with SEO optimization
- Product catalog with categories
- Search functionality
- PWA support
